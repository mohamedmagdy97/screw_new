# 2.2.1: مسح الألعاب اللايف من جوّه التطبيق

النسخة دي بتغني عن سياسة TTL في Firestore (اللي ما اتفعلتش بسبب خطأ 403).

## اللي اتغيّر
- لما صاحب اللعبة يدوس «وقّف اللايف» أو يخرج من شاشة النتايج، اللعبة بتتعلّم إنها خلصت وبعدين **بتتمسح من Firestore**.
- لو التطبيق اتقفل فجأة واللعبة لايف، الكود بيتحفظ على الموبايل، واللعبة **بتتمسح أول ما التطبيق يفتح تاني**.
- اللي بيتابع بيفضل شايف آخر نتيجة ومكتوب «صاحب اللعبة وقّف اللايف»، بدل «مفيش لعبة».
- إصلاح: نص الحالة في شاشة المتابعة كان بيطلع برّه الشاشة على الموبايلات الصغيرة.

## الخطوات بالترتيب
1. **قواعد Firestore (لازم قبل النشر):** القواعد الجديدة بتسمح بمسح اللعبة لو `ended` أو عدّى عليها `expireAt`.
   ```bash
   firebase deploy --only firestore:rules
   ```
   أو انسخ محتوى `firestore.rules` في Firebase Console ← Firestore ← Rules ← Publish.
2. ابني وارفع `2.2.1+17` زي العادي (`flutter build appbundle --release`).
3. **صفحة الخصوصية:** بعد ما النسخة تتنشر، انسخ `docs/privacy/index.html` لريبو `screw-new-privacy` (أو اعمل merge لفرع `update_2.2.1` فيه). النص الجديد بيقول إن اللعبة بتتمسح لما صاحبها يوقّفها بدل «بعد 24 ساعة».
4. TTL مش مطلوبة خلاص. لو اتفعّلت بعدين، `expireAt` لسه موجود وهتشتغل كاحتياطي.
